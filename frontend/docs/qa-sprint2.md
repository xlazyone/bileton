# Спринт 2 — тест-кейсы и проверка вёрстки афиши и расписания

WBS **4.6** «Тест-кейсы на отображение пустого расписания» и **4.7** «Проверка вёрстки на разных разрешениях, фикс багов».
Основание: [`docs/requirements/user-stories.md`](../../docs/requirements/user-stories.md) (US-01…US-06 и DoD).

## Как проверять

1. `cd frontend && npm run dev` → <http://localhost:5173>.
2. **Прогон на моках.** В шапке плашка «Демо-режим» или «Демо-афиша». Данные — `src/api/mockCinema.js`:
   - фильм «Тихая гавань» (`/movies/6`) — **без сеансов**;
   - «Последний рейс» (`/movies/4`) — только будущие сеансы;
   - «Тайна старого маяка» (`/movies/5`) — есть вчерашний сеанс, он не должен показываться;
   - сценарии через адресную строку: `/?mock=empty` (пусто), `/?mock=error` (сеть недоступна), `/?mock=slow` (загрузка 3 с).
3. **Прогон на реальном API** — после мержа задачи 4.3: в `frontend/.env.local` `VITE_USE_MOCKS=false`
   и `VITE_MOCK_CINEMA=false`, перезапустить `npm run dev`. Фильм без сеансов создать в БД.
4. Запросы смотреть в DevTools → **Network**.
5. Результат: ✅ — пройдено, ❌ — баг (issue по шаблону «Bug report», номер в «Комментарий»), ⏭ — не применимо.

Автотесты тех же сценариев: `npm test` (`tests/moviesPages.test.jsx`, `tests/schedule.test.js`, `tests/movies.test.js`, `tests/moviesContract.test.js`).

## 3. Вёрстка на разрешениях (4.7, US-06)

DevTools → **Toggle device toolbar** (<kbd>⌘</kbd><kbd>⇧</kbd><kbd>M</kbd> / <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>M</kbd>).
На каждом размере проверить `/`, `/movies/1`, `/movies/6`, `/sessions/101/seats` (после входа).

| ID | Размер | Что проверить | Ожидаемый результат | Результат |
|---|---|---|---|---|
| RS-01 | 375×812 (iPhone) | Афиша | 2 колонки карточек, названия переносятся, ничего не обрезано, нет горизонтальной прокрутки | Pass |
| RS-02 | 375×812 | Расписание | Постер слева от названия, сеансы по 2 в ряд, группы по датам сохранены, время читается | Pass |
| RS-03 | 360×740 (Android) | Афиша и расписание | Как RS-01/RS-02 | Pass |
| RS-04 | 768×1024 (планшет) | Афиша и расписание | 3–4 колонки карточек, сеансы в несколько колонок | Pass |
| RS-05 | 1440×900 (десктоп) | Афиша и расписание | 5 колонок карточек, контент по центру, не растягивается на всю ширину | Pass |
| RS-06 | любой | Длинное название фильма | Переносится, карточка не ломается | Pass |
| RS-07 | любой | Клавиатура | Tab проходит по карточкам и сеансам, видна рамка фокуса, Enter открывает | Pass |
| RS-08 | Safari и Chrome | Все страницы спринта 2 | Внешний вид одинаковый | Pass |
