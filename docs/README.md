# Документация проекта «БилетON»

Онлайн-сервис бронирования билетов в кино: выбор места на схеме зала
и генерация QR-кода вместо бумажного билета.
Учебный проект, шифр **ВПР41**.

**Команда:** Лебедев Иван (PM/Backend), Цихоцкий Андрей (Аналитик/QA),
Байдак Артём (Lead Dev/Backend), Скляров Антон (Frontend/QA).
