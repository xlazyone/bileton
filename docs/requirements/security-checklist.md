# Чек-лист тестирования безопасности модуля «Авторизация и профиль»

Область проверки: регистрация, вход, выход, выдача/хранение/валидация JWT, разграничение ролей viewer/controller, хранение паролей, обработка ошибок API.

Связанные артефакты: UC-01…UC-04 и DoD (пакет 3.1.1), таблица users (3.2.1), JWT и роли (3.2.2), формы и интеграция (3.3.1, 3.3.2), прогон тестов (3.4.2).

Правила валидации пароля: только минимальная длина ≥ 8 символов; проверка сложности (заглавные/цифры/спецсимволы) не выполняется.

Значения колонки «Статус»: `Не проверено`, `Pass`, `Fail`, `Отложено (спринт 4)`, `Не применимо`.

## 2. JWT: выдача, хранение, валидация

| ID | Как проверить | Ожидаемый результат | Приоритет | Статус | Комментарий |
| :---- | :---- | :---- | :---- | :---- | :---- |
| SEC-JWT-01 | Выполнить `POST /auth/login` с неверным паролем и с несуществующим email | Токен не выдан, ответ 401 | Critical | Не проверено |  |
| SEC-JWT-02 | Декодировать payload выданного токена (jwt.io или base64url) | Есть `sub` (id пользователя), `role`, `exp`; нет пароля и хеша | High | Не проверено |  |
| SEC-JWT-03 | Изменить один символ в подписи или payload и запросить `GET /auth/me` | 401 | Critical | Не проверено |  |
| SEC-JWT-04 | Сформировать токен с `alg=none` или другим алгоритмом и запросить `GET /auth/me` | Токен отклонён, 401: алгоритм берётся из настроек сервера | Critical | Не проверено |  |
| SEC-JWT-05 | Взять просроченный токен (или временно уменьшить `ACCESS_TOKEN_EXPIRE_MINUTES`) и запросить `GET /auth/me` | 401 | High | Не проверено |  |
| SEC-JWT-06 | Проверить логи и URL в процессе работы с токеном | Токен только в заголовке `Authorization`, в логах и URL отсутствует | High | Не проверено |  |
| SEC-JWT-07 | Зафиксировать, где фронтенд хранит токен, и оценить риск | Один вариант зафиксирован в документации (для MVP допускается memory/localStorage с записью о риске) | High | Не проверено | Нужно решение команды до 3.4.2 |
| SEC-JWT-08 | Выйти из аккаунта и повторить запрос старым токеном | Клиент удаляет токен; серверного отзыва JWT нет — токен действует до `exp` (осознанное ограничение MVP) | High | Не проверено | Для отзыва нужен blacklist — вне MVP |

| :---- | :---- | :---- | :---- | :---- | :---- |
