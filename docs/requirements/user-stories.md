**User Stories: просмотр афиши и расписания**  
**Модуль:** Афиша и сеансы (Спринт 2, пакет 4.1)  
**Связанные пакеты:** 4.2 (таблицы movies, sessions), 4.3 (эндпоинты GET /movies, GET /sessions), 4.4 (верстка), 4.5 (интеграция), 4.6 (тест-кейсы пустого расписания), 4.7 (проверка верстки и фикс багов).  
**1\. User Stories**  
**US-01. Просмотр афиши**  
**Как** Гость (или Зритель), **я хочу** видеть список фильмов, которые сейчас идут в кинотеатре, **чтобы** выбрать фильм, на который хочу пойти.  
**US-02. Просмотр расписания**  
**Как** Гость (или Зритель), **я хочу** открывать расписание выбранного фильма с датами и временем сеансов, **чтобы** выбрать удобное время для просмотра.  
**US-03. Информативность карточки сеанса**  
**Как** Гость (или Зритель), **я хочу** видеть в расписании зал и цену каждого сеанса, **чтобы** заранее понимать, где и за сколько я буду смотреть фильм.  
**US-04. Обработка пустого расписания**  
**Как** Гость (или Зритель), **я хочу** видеть понятное сообщение, если на выбранный фильм нет сеансов, **чтобы** не думать, что сайт сломался.  
**US-05. Переход к покупке билета**  
**Как** Зритель, **я хочу** нажать на конкретный сеанс, **чтобы** сразу перейти к выбору мест и покупке билета.  
**US-06. Просмотр с мобильного устройства**  
**Как** Гость (или Зритель), **я хочу** удобно просматривать афишу и расписание с экрана телефона, **чтобы** пользоваться сервисом в любом месте.  
**2\. Критерии Definition of Done (DoD)**  
**Для US-01 «Просмотр афиши»:**

* Страница афиши загружает данные из GET /movies.  
* В карточке фильма отображаются: постер, название, жанр(ы), длительность и возрастной рейтинг.  
* Если фильмов нет, отображается заглушка «Афиша пока пуста».  
* Страница доступна без авторизации (для Гостя и Зрителя).  
* При ошибке сети отображается сообщение и кнопка «Повторить».

**Для US-02 «Просмотр расписания»:**

* Клик по карточке фильма открывает страницу расписания этого фильма.  
* Данные запрашиваются через GET /sessions (с фильтрацией по movie\_id).  
* Сеансы сгруппированы по датам (сегодня, завтра, далее) и отсортированы по времени по возрастанию.  
* Прошедшие сеансы не отображаются как доступные.  
* Есть кнопка возврата к афише.

**Для US-03 «Информативность карточки сеанса»:**

* В карточке сеанса отображается время начала, номер/название зала и цена.  
* Данные о зале и цене берутся из ответа GET /sessions без дополнительных запросов.

**Для US-04 «Обработка пустого расписания»:**

* Если GET /sessions возвращает пустой массив (HTTP 200), отображается заглушка «На этот фильм пока нет сеансов».  
* Пустой ответ не интерпретируется как ошибка сервера.  
* Тест-кейсы на пустое расписание написаны и пройдены (пакет 4.6).

**Для US-05 «Переход к покупке билета»:**

* Клик по доступному сеансу передает session\_id в модуль бронирования (5.0).  
* Если пользователь не авторизован, показывается предложение войти/зарегистрироваться.  
* После успешной авторизации пользователь возвращается на страницу выбора мест с сохраненным сеансом.

**Для US-06 «Просмотр с мобильного устройства»:**

* Верстка карточек фильмов адаптируется под мобильные экраны (не ломается, элементы не обрезаются).  
* Расписание сохраняет группировку по датам и читаемость на экранах смартфонов.  
* Проверено на типовых разрешениях (мобильный / планшет / десктоп) в рамках пакета 4.7.
